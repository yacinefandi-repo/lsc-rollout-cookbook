# LSC Multi-Country Rollout Cookbook

A field manual for consultants and internal programme leads who run a multi-country rollout of Agentforce Life Sciences for Customer Engagement (Life Sciences Cloud), or move from Veeva CRM.

**Read it here:** https://yacinefandi-repo.github.io/lsc-rollout-cookbook/

## What's inside

- **Nine phases**, from mobilisation to run. The country localisation, migration, test and deployment phases repeat for every wave of countries.
- **Chapters for each area:** accounts, territories, products and content, visits, samples, consent, medical, and planning and KAM. Each chapter covers:
  - the workshop questions to ask, and what each answer means for the build
  - multi-country notes
  - "coming from Veeva" notes
  - pitfalls
  - test focus
  - an exit checklist
- **Process catalogue and fit-gap tool:** rate 43 processes per country and export the core, variant and gap results as CSV.
- **Deck kit:** 18 PowerPoint templates you can edit. They cover the programme kickoff, the discovery workshops, design review, core build showcase, wave kickoff, migration readiness, UAT kickoff, go/no-go, end-user training, hypercare and the steering committee. The plain files are in [`decks/`](decks/).

The site is a single HTML page with no build step and no tracking. Checklists and fit-gap ratings are saved only in your own browser.
